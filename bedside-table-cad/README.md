# Bedside Table CAD

A parametric bedside table/cabinet design for Fusion 360.

## Overall Dimensions
- **Width:** 450mm
- **Depth:** 400mm
- **Height:** 579mm (+ 40mm plinth)
- **Panel Thickness:** 19mm

---

## 📁 Build Instructions

### `stages/` — 16-Step Granular Build (Recommended)
Each step is a single focused task. Perfect for:
- Working with AI (clear memory between steps)
- Learning Fusion 360
- Methodical builds

**See:** `stages/README.md`

| Stages 01-05 | Stages 06-09 | Stages 10-11 | Stages 12-13 | Stages 14-16 |
|--------------|--------------|--------------|--------------|--------------|
| Carcass Panels | Enclosure | Miters | Corner Blocks | Finishing |
