# Stage 4: Joint Reinforcement

## Prerequisites
- Stages 1-3 complete (carcass with miters)

## Goals
1. **Create 8 corner blocks** - triangular hardwood braces (50×50×80mm)
2. **Position corner blocks** at Y=60mm and Y=334mm in each corner
3. **Add pilot holes** for screws (optional visual detail)

## Success Criteria
- [ ] 8 corner blocks exist, 2 per corner
- [ ] Blocks sit flush against both panels at each corner
- [ ] Blocks don't interfere with false floor or back panel

## Files
- `corner_blocks.py` - Block dimensions and positions

## Notes on Splines
Spline slots (hidden alignment grooves in miter faces) are typically cut
in the physical shop, not modeled in CAD. They're documented here for
reference but not built as 3D geometry.
