# Stage 01: Parameters

## Goals
1. **Create all user parameters** in Fusion 360's parameter table
2. **Verify derived values** calculate correctly

## Success Criteria
- [ ] 6 user parameters visible in Modify > Change Parameters
- [ ] Can reference parameters in sketches (e.g., `overall_width`)

## Parameters to Create

| Name | Value | Unit | Description |
|------|-------|------|-------------|
| `overall_width` | 450 | mm | Cabinet width |
| `overall_depth` | 400 | mm | Cabinet depth |
| `overall_height` | 579 | mm | Cabinet height |
| `carcass_thickness` | 19 | mm | Panel thickness |
| `back_thickness` | 6 | mm | Back panel |
| `false_floor_thickness` | 12 | mm | Divider shelf |

## Fusion Steps
1. **Modify > Change Parameters**
2. Click **+** to add User Parameter
3. Enter each parameter from table above
4. Click **OK** when done
