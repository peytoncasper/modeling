# Stage 15: Material Appearances

## Prerequisites
- Stage 14 complete (plinth created)

## Goals
1. **Apply wood appearances** to all bodies
2. **Differentiate materials** (carcass vs. back vs. blocks)

- [ ] Carcass panels match each other
- [ ] Corner blocks have hardwood look

## Fusion Steps

### Apply Appearances
1. **Modify > Appearance** (or press `A`)
2. In Appearance dialog, search for wood type (e.g., "Walnut")
3. **Drag** appearance onto body in canvas
4. Repeat for each body

### Batch Apply (same appearance)
1. Hold **Ctrl/Cmd** and click multiple bodies
2. Drag appearance to apply to all selected

### Adjust Grain Direction (optional)
1. Right-click appearance on body
2. Select **Edit Appearance in Body**
3. Adjust rotation/scale of wood grain

## Appearance Library Locations
- **Fusion 360 Appearances** > Wood
- Look for: Walnut, Oak, Birch, Maple, Cherry

## Verification
- Model looks like real wood furniture
- Different components are visually distinguishable
- Grain direction looks natural
