## How to Use

### Starting Fresh
1. Open `stages/01-parameters/README.md`
2. Follow the steps
3. Move to next stage

### Resuming After Break
1. Note which stage you completed
2. Open next stage's README
3. The README has all context needed

### With Fusion MCP
1. Share the stage README with AI
2. AI executes the Fusion commands
3. Verify success criteria
4. Move to next stage

## Stage Details

### Stages 01-05: Carcass Panels
Build the four main walls of the cabinet.

### Stages 06-09: Enclosure  
Add joinery (rabbets/dados) and internal parts.

### Stages 10-11: Miter Joints
Transform butt joints into clean 45° miters.

### Stages 12-13: Corner Blocks
Add triangular reinforcement braces.

### Stages 14-16: Finishing
Base platform, materials, final validation.
