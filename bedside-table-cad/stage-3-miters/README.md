# Stage 3: Miter Joints

## Prerequisites
- Stage 1 complete (4 carcass panels exist)
- Stage 2 complete (rabbets and dados cut)

## Goals
1. **Cut 45° miters** at all 4 corners where panels overlap
2. **Verify miter alignment** - diagonal seam should be clean
3. **Ensure structural integrity** - panels still meet properly

## Success Criteria
- [ ] All 4 corners show clean diagonal miter lines
- [ ] No overlap/interference between panels at corners
- [ ] Panels still form a closed box

## Files
- `miter_cuts.py` - Exact cut geometry for each corner

## Important Notes
- Miters are cut by removing triangular prisms from the overlap zones
- Each corner requires cuts to BOTH panels that meet there
- The miter line runs diagonally through the panel thickness
